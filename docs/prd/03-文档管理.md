# 文档管理与解析

> 返回 [PRD 总览](./README.md)

---

- **位置**：会议创建第二步；会议详情中的备课资料列表。
- **目标**：存储并解析备课文档，提取核心信息供 AI 对话使用。

## 3.3.1 文档状态机

| 状态     | 前端展示     | 说明                         |
|----------|--------------|------------------------------|
| uploaded | 解析中       | 刚上传，等待解析             |
| processing | 解析中（进度 N%） | 后台解析中                   |
| completed | 已完成       | 解析成功，可被 AI 使用       |
| failed   | 解析失败     | 展示错误信息                 |

- **解析进度**：`parse_progress` 0–100 动态展示；完成后显示「已完成」。

## 3.3.2 文档列表

- **加载方式**：进入页面时请求列表，分页或全量加载。
- **空态**：无文档时展示「暂无备课资料」。
- **单行信息**：文件名、大小（如 2.3 MB）、状态、操作（删除，如有权限）。
