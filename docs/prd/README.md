# 教师集体备课系统 - 产品需求文档（PRD）索引

## 1. 项目背景

- **需求简介**：构建一款智能教师集体备课会议系统，支持实时语音转写、AI 辅助对话、会议总结生成，旨在提升教研团队备课效率与讨论质量。
- **业务诉求**：解决线下备课会议记录分散、难以追溯、缺乏智能辅助的问题；通过语音转写、AI 问答、自动摘要，让教师聚焦讨论本身，减少记录负担。

## 2. 业务流程简述

用户注册登录 → 创建会议（填写基本信息、选择教师、上传备课资料）→ 进入实时会议（四阶段：主持人发言、教师发言、集体研讨、形成结论）→ 会议中 AI 实时转写、智能问答、网络资料检索 → 会议结束 → 生成摘要与要点 → 下载会议总结文档。

## 4. 核心功能速查表

| 模块 | 核心功能 |
|------|----------|
| 用户认证 | 注册、登录、JWT 鉴权 |
| 会议管理 | 创建、停止、完成、删除、列表、状态筛选 |
| 会议创建 | 三步：基本信息 → 上传 docx → 创建通义听悟任务 |
| 文档管理 | 上传 docx、异步解析、状态（uploaded/processing/completed/failed）|
| 教师管理 | 增删改教师、学科、声纹（可选）|
| 实时会议 | 四阶段（主持人发言→教师发言→集体研讨→形成结论）|
| 语音转写 | 通义听悟/科大讯飞 ASR 实时转写 |
| AI 对话 | 阿里云百炼，基于备课资料+讨论上下文的智能问答 |
| AI 语音 | TTS 朗读 AI 回复 |
| 网络资料 | 对话内容→AI 提炼关键词→SerpApi 搜索→AI 打标签 |
| 会议总结 | 通义听悟摘要与要点、下载 Word |
| 设置 | 教师、API Key、声纹、用户管理 |
| **短期** | 备课知识库、课标对齐、教案生成、多格式文档、会议回放 |
| **中期** | 观点对比与共识看板、教学资源推荐 |
